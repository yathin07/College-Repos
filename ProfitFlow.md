# ProfitFlow - AI Powered Finance Dashboard

This is my personal project built using **Next.js, Firebase, and Gemini AI**.  
The app helps track clients, invoices, expenses, and shows real-time financial insights with AI.

## 🚀 Features
- Secure Login with Firebase Auth
- Add & manage clients and invoices
- Visual finance dashboard (graphs & KPIs)
- Google Gemini AI insights (cost saving tips, earnings analysis)
- CSV Upload for bulk data input

## 🛠 Tech Stack
- Next.js 14
- Firebase Firestore
- TailwindCSS
- TypeScript
- Google Gemini API
